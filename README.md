# AccedeED

Aplicación móvil de accesibilidad educativa para Android.

## Características

- Navegación con Fragments
- Recursos educativos
- Eventos próximos
- Chat de soporte
- Perfil de usuario

## Requisitos

- Android Studio
- JDK 11+
- SDK 34

## Instalación

1. Clona el repositorio
2. Abre en Android Studio
3. Sincroniza con Gradle
4. Ejecuta en un emulador o dispositivo
